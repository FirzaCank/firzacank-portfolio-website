## Context

A banking collections operation: hundreds of agents, a multi-trillion-rupiah delinquent portfolio. Monthly reports arrived as separate Excel files with no unified view across agents, regions, or time — so questions like "who are our consistent top performers" or "where is recovery coming from" meant rebuilding the analysis from scratch every month.

## Problem

- Ten monthly Excel workbooks (Feb–Nov 2025), each with its own quirks: header drift, merged cells, inconsistent agent name spellings.
- Alarming headline numbers — 95.6% unconnected rate, 1.56% success rate vs a 15–25% industry benchmark — needed a defensible explanation, not just the metric.
- One agent had anomalous numbers (zero connected calls but the highest "paid count") that would distort any naive ranking and undermine trust in the dashboard.

## Approach

1. Built a Python ETL that ingests each monthly workbook, normalizes the schema, harmonizes agent identifiers, and outputs two clean partitioned datasets per month.
2. Layered a data-quality pass that flagged the anomalous agent for investigation rather than silently filtering it, keeping the ops conversation on top of clean data.
3. Designed a Looker Studio dashboard with three lenses (portfolio health, agent productivity, regional breakdown) so executives, team leads, and ops each land on the view that fits their decision.
4. Wrote the analysis as a narrative report — each finding paired with a root-cause hypothesis and a tiered recommendation (immediate / short-term / long-term).
5. Benchmarked top vs bottom decile agents on contact rate, PTP conversion, and call duration to surface coachable behaviors instead of a generic "improve performance" message.

## Outcome

The dashboard became the monthly review artifact — leadership, team leads, and the data team all working off the same numbers. The report reframed the 95.6% unconnected rate as a data-quality problem, not an agent-skill problem, redirecting investment toward contact-database validation and skip tracing. Top-performer benchmarks (10–15 min optimal call duration, 2–3 attempts per account, 15–20% PTP conversion on connected calls) gave the coaching program concrete targets, and the tiered recommendations turned a one-off audit into an executable action backlog.

The live dashboard is kept private under the client's data confidentiality terms.
